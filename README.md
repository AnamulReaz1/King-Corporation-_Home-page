# 👑 KING CORPORATION

Official website of **King Corporation**, developed using **Next.js 14**, **TypeScript**, and **Tailwind CSS**.  
This platform is designed to showcase the company’s ventures, values, and commitment to innovation with a sleek and modern interface.

---

## 🌐 Project Information

- **Domain:** [https://kingcorporation.store](https://kingcorporation.store)  
- **Domain Provider:** [Squarespace.com](https://www.squarespace.com)  
- **Domain Purchase Date:** **October 7, 2025**  
- **Deployment Platform:** [Vercel](https://vercel.com)  
- **Repository Type:** Private  
- **Framework:** [Next.js](https://nextjs.org)  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS 
- **UI Libraries:** Lucide Icons  
- **Animation:** Framer Motion  

---


## ✨ Features

- 🌗 Light & Dark mode with smooth theme transitions

- 🎨 Modern gradient design with glassmorphism effects

- 📱 Fully responsive for mobile, tablet, and desktop

- ⚡ Fast global delivery with Vercel CDN

- 🧩 Component-based architecture for scalability

- 🔄 Auto-deployment from master branch to Vercel

## 🔧 Deployment

This project is deployed using Vercel, ensuring continuous integration and delivery.
Every push to the main branch triggers an automatic redeployment.
